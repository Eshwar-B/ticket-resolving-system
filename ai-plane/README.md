# Enterprise AI Plane (Python 3.12)

The AI plane handles agentic workflows, RAG pipelines, model abstraction, guardrails, and evaluations.

- **FastAPI:** Model endpoints and webhook handlers.
- **LangGraph:** Stateful multi-agent supervisors and human-in-the-loop workflows.
- **Qdrant:** Vector search with mandatory tenant isolation.
- **Observability:** Structlog with OpenTelemetry trace and span injection.
